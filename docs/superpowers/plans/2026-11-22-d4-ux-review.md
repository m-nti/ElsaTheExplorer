> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-run `/ux-review` over the four UX specs against the committed Standard a11y tier and `interaction-patterns.md`, record the verdicts, and fix every in-scope doc defect the review finds.

**Architecture:** A docs-only task: the review rubric (`/ux-review` 3A) plus `consistency-check` are the gate in place of TDD. The report is written first so every edit traces to a finding; edits touch only `design/ux/*.md` and the canon allowlist rows those edits retire.

**Tech Stack:** Markdown; Node 26 / npm 11 gates (`npm run canon`, `npm run gate:tables`); GitHub CLI for the PR.

**Spec:** `docs/superpowers/plans/2026-11-22-v2-delivery.md` §1 D4 (#4); `design/ux/*.md`; `design/ux/interaction-patterns.md`; `design/accessibility-requirements.md`; `design/copy/copy-deck.md` (copy SSOT).

**Closes:** #4 · **Branch:** `docs/d4-ux-review-rerun` · **Base:** `6b9c50a`

## Global Constraints

- Canon: **Die Sammlung / The Collection**, verb **gesammelt / collected**, **four** cards per pack, **Der Abfahrtsaal**, no water content, at most one `!` per surface and never in errors/announcements/aria, no retired collection synonyms.
- Accessibility tier **Standard** (`design/accessibility-requirements.md`), WCAG 2.2 AA target.
- The copy deck is the string SSOT; a spec must quote it verbatim. `interaction-patterns.md` is the interaction SSOT; a spec must not re-specify a pattern differently.
- Docs-only: no code, no dependency, no deploy. Stops unchanged (force-push, history rewrite, deleting owner data).

## Review Focus

- **A string that reads right in DE and wrong in EN** — the four baseline canon defects are all EN (`Catalogue` in `reset.body` and the milestone announcement). Check both language cells, not just the German one.
- **A number stated twice in two units** — timer values (dialog close 200 vs 160, view switch 180 vs instant, reset close 150 vs 160) drift between a spec and the pattern library; grep every duration after editing.
- **A pattern referenced by name but contradicted in the body** — roving arrows (wrap vs stop), grid tab stops (per-tile vs one), swipe (navigate vs tilt-only), confetti (pack vs capstone). Each is invisible to the canon gate.
- **A wireframe that keeps the retired name** — ASCII wireframes are outside the canon gate's quoted-string scope (`KATALOG I`, `IM KATALOG?`). Read them, do not trust the gate.
- **A table broken by inserted prose** — `card-detail.md` §12 has rows after two paragraphs; `gate:tables` passes it. Render-check the section, not only the script.
