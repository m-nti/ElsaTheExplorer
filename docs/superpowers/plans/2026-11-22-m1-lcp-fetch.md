# #26 — One LCP image request (no duplicate fetch)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The first-view picture is fetched exactly once, from the one URL the app renders, at its true pixel size, with zero layout shift — and a gate that fails if the pre-refactor double fetch ever comes back.

**Closes:** #26 · **Branch:** `fix/m1-lcp-duplicate-fetch` · **Base:** `6b9c50a` · **Owner:** `performance-analyst` · **Cross-check:** `cs-frontend-engineer`

**Architecture:** The defect has two halves, and v2 removed both by construction: the shipped shell hard-coded `photos/thumbs/elsa-01.jpg` (111,920 B) and `app.js` then repointed the same element to `photos.php?thumb=…` (62,248 B), putting 174,168 B on the critical path for one picture. On this branch `index.html` ships no image and no image preload; `CardFace` renders `model.photo.src` once. So the work is to (a) prove the single request with a network trace, (b) mark the one visible image as the LCP element (eager + high priority) instead of preloading a URL the app cannot know before the manifest arrives, (c) pin both invariants with a gate whose negative proof is the legacy markup itself, and (d) clear the one acceptance criterion that measurably fails today: CLS, which is `0.0075` and comes from the Ultra display-face swap, not from the image.

**Tech Stack:** Svelte 5.59.1, Vite 8.3.8, Vitest 5.1.1, Playwright 1.65.1, Panda CSS 2.6.0, sharp 0.35.5 (dev).

**Spec:** `docs/audits/perf-baseline.md` (measured defect 2, "Kill the double LCP fetch"), `design/art/art-bible.md` §8 (ladder ceilings, loading policy), `docs/test-plan.md` §7.2 (`E-DLV-09`, `E-DLV-10`) and §8 (gate order).

## Global Constraints

- Image ladder 360 / 720 / 1200 / 1600; no original is ever served; the LCP picture is the tile rung ≤ 36 KB WebP / ≤ 55 KB JPEG today (the placeholder is 1,636 B).
- One URL per element. A preload is only legal when it names a URL the app itself renders — a guessed preload is the second request this ticket exists to prevent.
- Declared `width`/`height` are the derivative's intrinsic pixels (CLS 0 without layout guessing); `E-DLV-09` asserts them in the browser.
- Tokens are the only numeric authority; `var()` only in component-scoped CSS.
- Canon: at most one `!` per surface and never in errors; no water vocabulary.
- Accessibility tier Standard; the LCP image keeps its `alt` text.
- `npm run verify` is the local mirror of CI; a new check that must gate goes into an existing gate (Vitest `unit`), not into `.github/gates.json` — that chain is #25's surface.

## Review Focus

1. **A manifest-derived URL that a shell preload guesses** — the duplicate returns in a new shape (`?thumb=` vs `?image=&size=tile`); a mismatch is two cache entries for one picture.
2. **A `&v=` cache-buster that differs between preload and `img`** — same pixels, two requests; the gate compares the full URL including the query.
3. **A second visible image on the same page** (B3 seal preview plus card face) — "one LCP request" is per element, never "one image request on the page".
4. **Manifest dims reported unrotated** (`getimagesize()` before EXIF) — an attribute that disagrees with the decoded pixels is the CLS liability the baseline names.
5. **The `renderable: false` frame** — a photo that cannot decode must request no original and no second derivative; every image response stays inside the tile ceiling.

```ts
it("the shipped shell preloads no image URL the app does not render", () => {
  const sources = globSync("src/**/*.{svelte,ts}").map((path) => ({ path, text: repo(path) }));
  expect(auditLcpShell({ shellHtml: repo("index.html"), appSources: sources })).toEqual([]);

it("fails the pre-refactor markup: a shell thumb the script repoints", () => {
  const violations = auditLcpShell({
    shellHtml: `<img id="pack-preview" src="photos/thumbs/elsa-01.jpg" width="720" height="720">`,
    appSources: [{ path: "assets/js/app.js", text: `packPreview.src = "photos.php?thumb=elsa-01.jpg";` }],
  });
  expect(violations.map((v) => v.rule)).toContain("shell-image-rewritten");
});

it("fails a preload whose URL the app never renders", () => {
  const violations = auditLcpShell({
    shellHtml: `<link rel="preload" as="image" href="/photos/derived/tile/elsa-01.webp?v=1">`,
    appSources: [{ path: "src/App.svelte", text: `<img src="/img/photo-unavailable.webp" alt="">` }],
  });
  expect(violations.map((v) => v.rule)).toContain("image-preload-not-rendered");
});

it("fails a second image preload (art-bible §8 allows exactly one)", () => {
  const html = [
    `<link rel="preload" as="image" href="/a.webp">`,
    `<link rel="preload" as="image" href="/b.webp">`,
  ].join("\n");
  const appSources = [{ path: "src/a.ts", text: `"/a.webp" "/b.webp"` }];
  expect(auditLcpShell({ shellHtml: html, appSources }).map((v) => v.rule)).toContain("max-one-image-preload");
});
```

- [ ] **Step 3: Implement `auditLcpShell` in the test file**

Parse `shellHtml` for `<link … rel="preload" … as="image" … href="…">` and for `<img … src="…" …>` (attribute order free; strip `>` inside quotes). - [ ] **Step 1: Write the failing test**

```ts
// tests/e2e/lcp.spec.ts
test("the first-view picture is fetched once, at its own size, with no shift", async ({ page }) => {
  const seen = await measureFirstView(page);
  expect(seen.requests.filter((r) => r.url === seen.lcp.url)).toHaveLength(1);
  expect([...new Set(seen.requests.map((r) => r.url))]).toHaveLength(1);
  for (const r of seen.requests) expect(r.bytes).toBeLessThanOrEqual(55_000);
  const image = seen.images[0];
  expect(image.naturalWidth).toBe(image.width);
  expect(image.naturalHeight).toBe(image.height);
  // The LCP element is viewport-dependent (wordmark on desktop, picture on a
  // phone); if it is an image, it is this image.
  if (seen.lcp.element.startsWith("IMG")) expect(seen.lcp.url).toBe(image.src);
  expect(await page.locator("img.photo").getAttribute("fetchpriority")).toBe("high");
  expect(await page.locator("img.photo").getAttribute("loading")).toBe("eager");
  expect(seen.cls).toBe(0);
  const preloads = await page.locator('link[rel="preload"][as="image"]').evaluateAll((links) =>
    links.map((link) => (link as HTMLLinkElement).href),
  );
  expect(preloads.length).toBeLessThanOrEqual(1);
  for (const href of preloads) expect(href).toBe(seen.images[0].src);
});
```

**Interfaces:**

- [ ] **Step 1: Prove the cause with one variable**
