# CardFace Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver B2 — one card component whose fixed zones, photo window, five-layer foil, tilt, focus behaviour and error frame are all proven, and a 3-card + holo slice that closes ADR-0002 spike 1.

**Architecture:** Zone geometry lives in a typed constant mirrored from `design/art/art-bible.md` §8 and consumed as Panda tokens; the component renders those zones with Svelte 5 runes and scoped CSS that reads `var(--tier-*)` only. Pure functions (`card-zones`, `card-photo`, `tilt`, `render-mode`) carry the logic so Vitest can prove it; Playwright proves the rendered slice (overflow, focus, reduced motion).

**Tech Stack:** Svelte 5.59.1 runes, Vite 8.3.8, TypeScript 7.0.2 (+6.0.3 for `svelte-check --tsgo`), Panda CSS 2.6.0 typed tokens, Vitest 5.1.1, Playwright 1.65.1, Node 26.

**Spec:** `design/art/art-bible.md` §8 (authoritative bands), `design/ux/card-detail.md` §5.3/§6/§10/§12, `design/tokens/tokens.ts`, `docs/test-plan.md` §5.8/§6.3/§6.4/§6.6/§6.7, `docs/adr/ADR-0002-styling-system.md`. ADR-0011 is in review (PR #41) and is cited, not treated as merged.

## Global Constraints

- Bands (art-bible §8, merged D12a): plate **15.5** / photo **41.5** / strip **5.5** / story **19.5** / stats **8.5** / foot **5** / gutters **4.5** = 100. Tile column: **15.5 / 44 / 5.5 / 16 / 9 / 5.5 / 4.5**.
- Reference card 340 × 485.71, plate inner 469.71 px, em root 13.6 px (`4cqw`). Photo window 4:5, fills its band with **no block padding**, **155.94 px = 45.87 %** of card width.
- Plate is **two rows**: name (one line, `text-overflow: ellipsis`) then number + mood + rarity chip. Pressure order: credit → mood → print line → copy clamp.
- Foil is **five layers** (rim, chip, photo, etch, glitter/glint/rays), consuming `var(--tier-*)` only; no raw colour, no runtime CSS-in-JS.
- Canon: Die Sammlung / gesammelt, no water, at most one `!` and never in error/aria copy. Star label waits on **#51**.
- Accessibility tier Standard: focus return, announcements via `#live-status`, reduced-motion final frame.
- Every task ends with `npm run verify` green (13 gates) and a commit naming the ticket.

## Review Focus

- **Text overflow at 180–340 px** — DE copy is ~40 % longer than EN; the clamp must not hide the name behind an ellipsis at 340 px. Test: `U-CV-01…07`, `E-OVF-01…12` (T5, T9).
- **Reduced motion on the foil** — no movement may carry information; the final frame is the layout. Test: `E-RM-03/08` (T6, T7).
- **Focus return after close** — deep link, error state, disabled trigger; never `<body>`. Not in this slice (no dialog): `E-FOC-01…16` are exercised in B4/B6.
- **`renderable:false`** — the printed frame, no image request. Test: `E-IMG-09` (T8 adds the row; `E-IMG-04` is the HEIC case).
- **Latin-1 vs EN length** — the same field passes DE and overflows EN; both widths pinned (T5, T9).

### Task 2: Zone table as typed data

**Files:**
- Create: `src/lib/domain/card-zones.ts`
- Test: `tests/unit/card-zones.test.ts`

**Interfaces:**
- Produces: `CARD_ZONES: Readonly<Record<"plate"|"photo"|"strip"|"story"|"stats"|"foot"|"gutters", number>>`, `CARD_ZONES_TILE` (same keys), `zoneSum(zones): number`, `photoWidth(cardWidth: number): number`.
- `photoWidth` must subtract the card face's 16 px (2 × 8 px) padding before applying the band: `((w / 0.7) - 16) * (CARD_ZONES.photo / 100) * 0.8`. The un-subtracted form returns 161.26 px and fails the 155.94 assertion.

- [ ] **Step 1: Write the failing test**

```ts
import { CARD_ZONES, CARD_ZONES_TILE, zoneSum, photoWidth } from "$lib/domain/card-zones";

it("matches art-bible §8 and sums to 100", () => {
  expect(CARD_ZONES).toEqual({ plate: 15.5, photo: 41.5, strip: 5.5, story: 19.5, stats: 8.5, foot: 5, gutters: 4.5 });
  expect(zoneSum(CARD_ZONES)).toBeCloseTo(100, 5);
  expect(zoneSum(CARD_ZONES_TILE)).toBeCloseTo(100, 5);
});

it("gives a 155.94 px window at the 340 px reference", () => {
  expect(photoWidth(340)).toBeCloseTo(155.945, 2);
});
```

- [ ] **Step 2: Run it** — `npx vitest run tests/unit/card-zones.test.ts` → FAIL (module not found).

- [ ] **Step 3: Implement** — the constants above; `photoWidth = (w) => (((w / 0.7) - 16) * (CARD_ZONES.photo / 100)) * 0.8`.

- [ ] **Step 4: Run it** → PASS. **Step 5: Commit** `feat(card): zone table as typed data (#13)`.
